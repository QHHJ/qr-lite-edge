## 浏览器验证范围

- 双二维码图片识别、全部坐标标记、结果选择与切换。
- 复制所选内容。
- 本地图片上传，以及模拟图片粘贴与拖放事件。
- 当前可见页面截图识别。
- 1.5 倍像素比例下拖拽矩形区域扫描。
- 同源网页图片读取函数。
- 图片识别阶段未观察到外部 HTTP 请求，未出现页面脚本异常。

原生右键菜单点击本身未自动化验证；摄像头、Firefox 以及各类跨域网页还需人工验收。本地测试样本与截图输出到 .local/，不会进入源码仓库或源码压缩包。

构建保留 3 个 Webpack 性能警告，主要涉及离线 WASM、模型和弹窗脚本的体积。此处保留离线识别资源，未改成外部下载。

本次整理添加了 MIT 许可证文本、上游及组件来源说明，并使生产构建包含许可证和第三方声明。GitHub 工作流检查 lint 和 Edge 构建；浏览器验证在本地运行。
